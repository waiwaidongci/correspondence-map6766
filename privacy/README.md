# 匿名列联表 · 隐私分组发布

零第三方依赖（仅 Python 3.11 标准库 + 原生 JS）的列联表隐私发布服务。
对外发布按**行列类别分组**的计数，自动保护低于阈值的小正计数格，
并在**联立本次与全部既往发布**后，逐保护格给出可行整数范围；
任一保护格只有 1 个可能值即拒绝发布。

## 启动

```sh
python3 -m privacy.run          # 默认 http://localhost:18333
python3 -m privacy.run 19000    # 指定端口
```

数据存于 `privacy/data/privacy.db`（SQLite），可用环境变量
`PRIVACY_DB_PATH` 覆盖。浏览器打开首页即可操作，无需构建前端。

## 需求与实现对照

| 需求 | 实现 |
|---|---|
| 按行列类别分组发布计数 | 行/列各提供一个划分（完整覆盖、互不相交），块计数为组内底表格之和 |
| 隐去小格，防合计反推 | 任一底表格满足 `0 < 计数 < 阈值`，其所在分组块**强制隐去**；可再手动补隐其他块 |
| 低于阈值的正计数须保护 | `engine.protected_cells` 识别保护格；零格与达标格不强制保护 |
| 保留各组行/列合计 | 每次发布同时输出每个行组、列组的合计与总量，并作为等式约束参与推断 |
| 联立本次及所有既往发布 | 全部历史安全发布 + 候选发布统一转成底表变量上的 0/1 线性等式后联合求解 |
| 逐个保护格给可行整数范围 | 整数可行性 + 二分搜索求每格最小值/最大值与可能值个数 |
| 至少两个可能值才准发布 | 任一保护格 `max-min+1 < 2` 即拒绝，并列出具体格与原因 |
| 不同分组共用同一底表 | 一个研究（底表）下可有任意多次不同分组的发布，共享同一组变量与历史 |
| 历史发布保留可查 | 每次发布（含被拒）落库，序号连续，页面可查、可下载 |
| 底表校订后停用，另建研究再发布 | 有历史发布时校订 → 原研究置 `retired` 并克隆新研究；无历史则原地校订 |
| 预览 / 正式发布 / 下载 | 预览走只读事务不落库、不占历史；正式发布落库；CSV 下载脱敏计数 |
| 并发发布按合并公开信息判断 | 正式发布在**单事务**内 读既往→合并评估→写入，进程写锁 + `BEGIN IMMEDIATE` 串行化，杜绝各自安全、合起来泄露 |

## 安全模型（整数推断）

底表每个格是一个非负整数变量。一次发布产生三类 0/1 系数线性等式：

- 未隐去块：块内各格之和 = 发布块计数；
- 行组合计：组内各行全部格之和 = 行组合计；
- 列组合计：组内各列全部格之和 = 列组合计。

求解器（`server/engine.py`）：

1. **边际收紧初始上界**：每格不超过其所在任一行组/列组合计；
2. **区间传播**：用线性和等式反复收窄每个变量的上下界；
3. **完全 DFS 整数可行性** + 对目标变量二分搜索最小/最大值；
4. **双重预算安全失败**：全局节点预算 + 墙钟时间预算。NP 难最坏情形下
   无法保证快速精确求解，预算耗尽即抛 `Inconclusive`，上层按**拒绝发布**
   处理——宁可不可发布，也绝不放行不确定结论。

引擎正确性由 `tests/test_engine.py` 对小例做**完整枚举（暴力）对照**验证。

## 目录

```
privacy/
├── run.py                 # 启动入口
├── server/
│   ├── db.py              # SQLite 持久化、事务/写锁
│   ├── engine.py          # 整数推断引擎（传播+DFS+预算安全失败）
│   ├── service.py         # 分组/隐去/评估/发布/校订/CSV
│   └── app.py             # 标准库 HTTP 服务 + 静态托管
├── web/                   # 原生 JS 单页前端
└── tests/                 # 四套测试，run_all.sh 一键运行
```

## HTTP API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/studies` | 研究列表（含安全发布数） |
| POST | `/api/studies` | 新建研究（底表、标签、阈值） |
| GET | `/api/studies/{id}` | 研究详情 |
| POST | `/api/studies/{id}/preview` | 预览（只读，不落库） |
| POST | `/api/studies/{id}/publish` | 正式发布（单事务合并判断） |
| POST | `/api/studies/{id}/revise` | 底表校订（停用+克隆 / 原地） |
| GET | `/api/studies/{id}/publications` | 发布历史（含被拒） |
| GET | `/api/download/{pub_id}` | 下载脱敏计数 CSV（UTF-8 BOM） |

发布请求体示例：

```json
{
  "title": "2026 秋季对外发布",
  "row_groups": [[0, 1], [2, 3]],
  "col_groups": [[0], [1, 2, 3, 4]],
  "extra_suppressed": [[0, 1]]
}
```


- `test_engine`：保护格识别、唯一值拒绝、与完整枚举逐格对照、两次发布累计收窄；
- `test_service`：全工作流、预览不落库、校订停用克隆、并发 6 线程串行合并、
  各自安全但联立泄露的拒绝、输入校验；
- `test_safety`：时间/节点预算安全失败、12×12 最大规格有界运行；
- `test_http`：真实起服务走 JSON API 全流程与 CSV 下载。

## 边界与说明

- 支持 2–12 行 × 2–12 列、每格 0–1,000,000 非负整数、总量 ≤ 144,000,000。
- 推断只使用发布中确实公开的等式；被拒发布不进入公开信息，仅留痕审计。
- 安全失败是**保守拒绝**：求解器在预算内无法确证安全时拒绝该发布，
  不会给出可能偏宽的“伪安全”范围。
- 本模块为合成汇总数据设计，不含个人身份信息；不替代差分隐私等形式化保证。
